Google Cloud API key

Lectern uses your own Google Cloud key to call the Vision API (for reading pages) and the Text-to-Speech API (for the voice). Create a key in the Google Cloud Console, enable the Cloud Vision API and Cloud Text-to-Speech API on that project, then paste the key below. It's stored only in this browser, never sent anywhere but Google. Since it lives in this page's code, restrict the key to those two APIs and to this site's URL under the key's settings.
